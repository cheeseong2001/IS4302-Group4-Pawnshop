# IS4302 Group 4 Pawnshop

This project is a P2P Pawnshop on Ethereum.

Try running some of the following tasks:

```shell
npx hardhat help
npx hardhat test
REPORT_GAS=true npx hardhat test
# deploy to local
# open first terminal
npx hardhat node
#open second termial
npx hardhat clean #optional
npx hardhat compile
npx hardhat deploy --network localhost
npx hardhat gui
```
